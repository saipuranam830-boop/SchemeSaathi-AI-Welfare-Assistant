Build a complete, modern, responsive full-stack web application named:

**“Government Welfare Scheme Eligibility Assistant”**

Project concept:
An Agentic AI-based Government Scheme Eligibility Assistant using **LLMs + RAG + Agentic AI** to help Indian citizens discover government welfare schemes, check eligibility, understand required documents, get application guidance, and track deadlines.

The system should use official government scheme information as the primary knowledge source. The application must be simple enough for rural citizens, students, farmers, women beneficiaries, senior citizens, and other citizens to use.

The project architecture must include:

* LLM layer
* RAG retrieval layer
* Agentic AI layer
* Government scheme database
* User profile
* Eligibility verification
* Document verification
* Personalized recommendations
* Application guidance
* Deadline monitoring
* Multilingual chatbot

The proposed system should follow this flow:

Citizen Query
→ Citizen Profile Agent
→ Eligibility Agent
→ Document Verification Agent
→ RAG Retrieval Layer
→ LLM Reasoning Layer
→ Recommendation Agent
→ Deadline Monitoring Agent
→ Personalized Scheme Guidance

10. AGENTIC AI WORKFLOW
=======================

Implement separate logical agents/services.

Agent 1:
Citizen Profile Agent

Responsibilities:

* Understand user profile
* Extract structured information
* Identify missing information

Agent 2:
Eligibility Agent

Responsibilities:

* Compare citizen information with scheme eligibility criteria
* Identify eligible / potentially eligible / not eligible
* Explain which conditions were satisfied
* Identify missing requirements

Agent 3:
Document Verification Agent

Responsibilities:

* Check uploaded documents
* Identify document type
* Extract relevant information where technically possible
* Compare information with user profile
* Report missing or inconsistent information

Agent 4:
Scheme Retrieval Agent

Responsibilities:

* Search the scheme database
* Retrieve relevant government documents
* Perform semantic retrieval
* Return relevant scheme information to the LLM

Agent 5:
Recommendation Agent

Responsibilities:

* Analyze retrieved schemes
* Personalize recommendations
* Explain why each scheme is relevant
* Avoid recommending schemes when required eligibility information is unavailable

Agent 6:
Deadline Monitoring Agent

Responsibilities:

* Check application deadlines
* Identify upcoming deadlines
* Show deadline notifications
* Notify users about important dates

26. IMPORTANT AI SAFETY / ACCURACY RULE
=======================================

The application must distinguish between:

Verified official information
AI-generated explanation
User-provided information

Never claim that a citizen is officially approved for a scheme.

Use wording such as:

“Based on the available eligibility criteria, you appear potentially eligible.”

Final approval remains with the relevant government department.

When scheme information is outdated or unavailable, clearly show:

“Information could not be verified from the latest available official source.”
